## Release 正文

# 远日点 APHELION 0.1.0a2

本次 alpha 更新集中修复事件日志丢失，并改善母星时代的建造反馈。

## 特性

- 建造放置时显示内核返回的具体原因，包括资源不足、地块占用、地形不符与时代未解锁。
- 母星时代隐藏尚未解锁的星区态势、科技树和星际航线面板，减少无效信息。

## 修复

- 修复 2× / 4× 速度下建造、研究和来袭等事件在快照编码前被清除的问题。
- 修复暂停、后台标签页和渲染掉帧时新事件未进入日志、字幕与警报的问题。
- 同波次不同落点的掠袭事件分别保留，不再被合并成一条日志。

## 其他

- `node scripts/ci.mjs --web` 现在只执行前端检查，完整模式仍包含 Rust、WASM 与双 exe 打包。
- 新增内核事件、暂停事件和 T1 HUD 回归测试；同步 Rust 工具链与事件交付文档。
- 两个 exe 均未做代码签名，首次运行如触发 SmartScreen，请确认文件名与发布来源后再运行。

## 安装

- `APHELION-0.1.0a2.exe` —— 桌面版（推荐，需要 Windows WebView2）。
- `APHELION-0.1.0a2-browser.exe` —— 浏览器兜底版（启动本地服务并打开默认浏览器）。
