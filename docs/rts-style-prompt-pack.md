> **历史参考（旧版）**：本文保留早期军工终端探索，不再作为现行美术规范。当前以

> **2.5D 等距世界 + 军工指挥终端 HUD + 全程序化绘制**。
> 本文档给三样东西：① 一句可直接前缀的风格 token；② 跨题材通用提示词；③ 题材替换表 + 验收标准。

## 三、跨题材通用主提示词（占位符版，直接粘贴）

```text
用纯代码（Canvas 2D + DOM/CSS，禁止任何位图素材、emoji、图标字体）制作：⟨题材 / 内容，例如：等距视角的太空站基地管理界面、蒸汽工厂调度看板、古风城建经营、末日避难所运营⟩。

复刻一套「等距指挥终端」风格系统，而不是某个具体游戏的皮肤。以下 10 条是风格基因，不可改动；只替换题材内容与功能模块。

【风格基因】
1) 视角：2:1 菱形等距（或 3/4 正交俯视），固定机位，无透视畸变；所有体积物由等距盒体拼成。
2) 渲染质感：2.5D 预渲染 sprite 感——不是像素风、不是 3D 实时渲染；硬边、无描边、无 bloom、无景深。
3) 光照：全图统一左上光。体积物三面 = 顶面 ×1.0 / 右面 ×0.86 / 左面 ×0.68；顶棱与左棱 1px rgba(255,255,255,.55) 亮边，下棱与右棱 1px rgba(0,0,0,.45) 暗边；底部短而柔的椭圆接触阴影，统一偏向右下。
4) 表面：硬边拼花（瓦片 / 地砖 / 金属格栅），每块 = 底色 + 两层低频噪声斑块（10~18px / 4~6px，透明度 8~14%）+ 1~2% 逐像素 dither + 1px rgba(0,0,0,.10) 暗缝；不同材质硬边相接，禁止大面积渐变。
5) 色彩规则：压深黑位（#050C0C / #0B1416 / #1D272B），整体低饱和；全图最多 1 个主强调色 + 1 个功能色 + 1 个状态色：
   主强调 琥珀金 #F0C050 —— 只用于数值、激活态、关键按钮、开关；
   功能青 #88D8E8 —— 只用于进度条 / 连接线 / 选中反馈；
   状态绿 #90C0A0 —— 只用于监测、正常状态、地图标记。
   金色不得做大面积背景，青色不得用于文字，三色不同时出现在同一控件上。
6) HUD 材质：哑光近黑钢板 + 1px 冷钢描边 #4E5C60 + 顶部 1px 内高光 rgba(255,255,255,.06)；直角或 ≤2px 圆角；短阴影 0 2px 6px rgba(0,0,0,.5)。禁止玻璃拟态、模糊、大阴影、发光边框、彩色渐变卡片。
7) 字体：中文 Noto Sans SC 700，字号只用 10 / 11 / 12 / 13 / 14px；英文作副标题：10px 大写、letter-spacing .30em、色 #9AA4A6；数字、时间、倒计时用等宽字体；行高 1.4；组件间距 6px。
8) 信息密度：每个面板固定三段式 = 标题行（中文 12~13px + 右侧宽字距英文小字）/ 数据或列表 / 细进度条或状态点；大量 1px 分隔线 #2C383E；图标只用 16px 内联 SVG 线性图标（stroke 1.5，currentColor），禁止 emoji、禁止位图图标。
9) 动效克制：进度条平滑过渡、数字滚动、雷达/扫描线；无弹跳、无粒子、无发光、无 3D 翻转。
10) 实现约束：全部程序化生成（Canvas / CSS / SVG）；固定随机种子（mulberry32）保证截图可复现；60fps；Network 面板不得出现图片请求。

【HUD 骨架（内容可换，骨架不动）】
- 顶栏 28px：状态点 + 时间 + 3 个关键数值 + 操作提示（11px #A8B0B2）+ 暂停按钮。
- 右侧竖向仪表栏 320px：上部主视图 canvas（296×140：栅格 + 同心圆 + 扫描线 + 菱形光点，可换成资源分布图/流程图/小地图）；中部 3 行「任务 / 技能 / 产出」行（名称 13px + 右侧琥珀数值 + 3px 细进度条）；下部 2×2 操作按钮（深色钢板态 + 1 个金色激活态）。
- 左下浮动面板 320×245：标题行（宽字距英文 + 快捷键）、2 条金色主开关行、两组三段选择器、底部灰色脚注。
- 底部居中字幕：说话人标签（状态绿）+ 2px 竖线 #4E5C60 + 文本。

【题材替换规则】
把具体名词换成你的题材，但保留上面的骨架、材质、色彩规则与信息密度。不允许因为题材变化而改成圆角大卡片、彩色渐变、卡通描边或 3D 反光材质。

【交付顺序】
先输出：色板 token + 版式骨架 + 静态 HUD 截图；确认后再做世界/主视图；最后做交互与动效。每一步给截图，不要一次性写完。
```

## 五、三个换题材示例（只示意方向）

- **太空站管理**：主视图换成舱段俯视图；技能行换成"氧气循环 / 反应堆 / 对接窗口"；页签换成"舱段 / 系统 / 人员 / 补给"；色板不变（琥珀金做能量值，青色做维生进度，绿做状态正常灯）。
- **蒸汽工厂调度**：主视图换成管线拓扑；页签换成"产线 / 锅炉 / 工人 / 库存"；地面材质换成铸铁格栅 + 油污 dither；体积物换成锅炉、管道、烟囱（仍是等距盒体 + 冷却塔式圆柱）。
- **工具 / 数据看板（非游戏）**：只取 HUD 那一半——黑钢面板、琥珀金强调、青色进度、宽字距英文副标题、等宽数字、1px 分隔线；去掉等距世界，主视图换成图表/拓扑即可。
- **古风城建**：世界换成木构、瓦顶、稻田，但 HUD 仍保持指挥终端材质（这种"古代内容 × 现代终端"的反差正是风格的一部分）。

## 六、纯代码执行配方（跨题材通用）

**投影**：`tileW=64, tileH=32`；`sx=(gx-gy)*32, sy=(gx+gy)*16`；菱形顶点 `(0,-16)(32,0)(0,16)(-32,0)`；瓦片绘制 65×33、重叠 1px 防缝；实体按 `(gx+gy)` 画家排序。

**材质**：`底色 → 2 层噪声斑块（12px/5px，透明 8~14%）→ 1.5% dither 噪点 → 1px rgba(0,0,0,.10) 暗缝`；道路/走廊加 1px 亮暗双边 + 中心虚线；每类材质预渲染 2~3 个变体到离屏 atlas。

**体积物**：等距盒体 = 顶面菱形 + 左面平行四边形(×0.68) + 右面(×0.86)；1px 亮/暗棱边；细节（竖分缝 9px 间隔、污渍、玻璃带 3px + 1px 高光、黄黑 45° 斜纹、红白交替栏杆）；底部椭圆软阴影（径向渐变 rgba(0,0,0,.30)→透明，压扁 0.45）。

**sprite**：4× 离屏绘制再缩小；轮廓 1px 暗边；顶部 2~3 个 1px 高光点；8 方向朝向缓存。

**HUD CSS**：面板 `background:rgba(5,12,12,.94); border:1px solid #4E5C60; border-radius:0; box-shadow:inset 0 1px 0 rgba(255,255,255,.06), 0 2px 6px rgba(0,0,0,.5)`；激活按钮 `linear-gradient(#F6D06A,#D9A62E)` + `#FFE08A` 边 + 文字 `#241A08`；进度条 3px（轨道 #1B3A42 / 填充 #88D8E8）；分隔线 1px `#2C383E`。

**字体**：Noto Sans SC 700（回退 Microsoft YaHei / PingFang SC）；数字 `ui-monospace, "Roboto Mono"`，`font-variant-numeric: tabular-nums`。

**性能**：地形/实体全部预渲染缓存，运行时只 drawImage；视口裁剪；60fps。

## 七、风格验收 10 问（任何题材都适用）

1. 视角是否固定等距/正交、无透视畸变？
2. 所有体积物是否都有三面明暗（1.0 / 0.86 / 0.68）+ 1px 棱边？
3. 地面是否硬边拼花 + 暗缝，没有大面积渐变？
4. 面板是否哑光近黑 + 1px 钢边 + 直角（≤2px）？
5. 全图高光是否只有 1 个主强调色？青色是否只出现在进度/连接？
6. 字体层级是否只有 10/11/12/13/14px，中文 700、英文宽字距、数字等宽？
7. 图标是否全部 16px 线性 SVG，没有 emoji、没有位图？
8. 每个面板是否都是"标题行 + 数据/列表 + 细进度条/状态点"？
9. 阴影是否统一方向、短、柔？
10. Network 面板是否 0 图片请求、0 模糊滤镜、0 发光？

## 八、翻车点

1. 把风格理解成"RTS 元素"——雷达、超武、沙盒是皮肤，换掉不影响像不像；**材质 + 版式语法 + 配色规则**才是风格。
2. HUD 画进 canvas → 文字糊、1px 变 2px。HUD 一律 DOM。
3. 题材一换就放飞：圆角卡片、彩色渐变、卡通描边、3D 反光。用上面的负面约束压住。
4. 图标用 emoji 或图标字体 → 换机器就变形。
5. 地形用大渐变过渡 → 失去拼花质感。
6. 没有固定随机种子 → 截图无法复现、验收无从谈起。
