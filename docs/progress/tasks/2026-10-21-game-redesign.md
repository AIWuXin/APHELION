# 2026-10-21 · 游戏重新设计（讨论 → 方案 → 实施）

## 背景

现有玩法（0.1.0a0）是此前 deepseek 自动生成的：单星球殖民地 + 5 波防御获胜。用户不满意，要按自己的设想重新设计。本档案记录讨论结论；定稿后再落到 `docs/design.md`（面向读者的产品文档）。

## 用户总体设想（2026-10-21 记录，原文要点）

星球殖民建造 → 防御敌人并攀升科技 → 太空计划火箭发射 → 星际科技树 → 防御或进攻星际敌人 → 发展星际帝国 → **最终统治银河系，破解中心黑洞的秘密**。

阶段轴：母星阶段（当前焦点）→ 太空计划 → 星际扩张 → 银河帝国 → 黑洞终局。

## 设计原则（讨论中逐步形成）

- 母星阶段要有「殖民建造 + 科技攀升」的层次感。
- 自然资源数量克制（用户明确要求：几个就够，不要复杂）。

## 讨论记录

### 话题1：母星阶段的自然资源（2026-10-21，**已定案**）

- 参考系：戴森球计划的「资源梯度逼扩张」骨架，但砍到 6 种、无多级加工链（DSP 搜索接口 402 未用，凭认知对照）。
- 挥发物：讨论后**砍掉**（与石油职责重叠）。
- 定案（用户拍板 2026-10-21）：
  - **T1 金属矿脉 + 煤矿**（基础工业：建造骨架 / 火电补光伏晨昏缺口）
  - **T2 石油**（化工：火箭燃料、合成材料）
  - **T3 铝矿**（太空计划门槛：火箭壳体、轨道设施）
  - **T4 钛/硅**（少量分布、提取复杂，主做芯片：高级实验室/雷达/政策）
  - **T4 末期火箭发射**——母星阶段规划到此为止。
- 单极磁石：推迟到星际时代再议，倾向「黑洞/中子星专属 + 母星痕量做剧情钩子」，未定。
- 记录在案的配套考虑：开采手感分三类（矿脉矿机 / 油井持续流 / 钛硅复杂提取）；HUD 资源栏届时需分组（基础/工业/稀有）。
- 未决（下轮话题候选）：各 T 级建筑链与科技树对应表；研究点 vs「科技吃资源制品」；防御体系在新资源下的造价与弹药归属。

### 话题2：物流模型 + T1 建筑与敌人（2026-10-21，**已定案**）

- 用户提问：没有传送带，资源怎么流动？现状答案：**全局魔法库存**——所有建筑直接读写同一资源池，无任何物流层（连「点击设置输出」都没有）。
- **物流定案 = C 方案：半径免物流 + 跨区运输队**。仓储/中枢覆盖半径内资源自由流动；超半径的前哨矿点用运输无人机/车队实体搬运。设计意图：T1 期体验≈全局库存零负担；远处矿点（铝/钛硅）产生补给线，掠夺者可掐矿路 → 涌现式防御玩法，缝合「殖民+防御」两支柱。中枢自带初始仓库半径（随决策一并确认）。
- **T1 建筑定案**：指挥中枢、光伏阵列（**发电低**）、金属矿机、采煤机、火电站（**发电高**，烧煤填晨昏缺口→T1 主力电源）、电磁炮塔、掩体。T1 故意没有实验室与防空（制造爬 T2 的内驱力）。
- **T1 敌人定案**：纯地面——掠夺者小队从地图边缘掠袭入场（不走空投，因 T1 无防空）；破城者留 T2/T3；登陆艇+巡洋舰轨道威胁整体推到 T2，与防空阵列成对解锁。

### 话题6：资源空间分布（2026-10-22，**已定案**）
- 用户定案：T1 金属+煤应**遍布星球**；石油等 T2+ 资源可远距离分布，配合 T2 解锁**火车等远程运输装置**。
- 落地为**两层分布**：富矿层（群系亲和大矿脉，选址战略）+ 散布层（任何陆地群系 1-4 格小矿点、richness 30-60、能活不饱）。散布层已实现（见 [2026-10-22 散布层任务]）。
- **设计调整**：物流运输队原计划 T3 → **提前到 T2（火车）**，与石油的开采半径匹配；T2 石油定为强地域性远距离资源（沉积盆地之类群系绑定，具体分布待 T2 设计）。
- **密度定案（2026-10-22）**：全星球 **9%** 面积存在某种矿（陆地口径 ~14%，矿/煤各半）；出生点 **500 格内必有金属+煤**（契约测试锁死）。
- **未来规划（用户点名记下）**：**创建世界界面**——玩家可自由调节世界生成参数（种子、矿藏密度、海陆比、气候等）。届时把 climate/minerals 的阈值常量提为创世参数结构体。

### 未来规划备忘（2026-10-21 记录，暂不做）

- **敌人基地机制**（类异星工厂）：敌人从附近基地产生，基地不摧毁会越来越强。等用户实测 T1 后再设计。

### 话题3：美术品质（2026-10-21，责任人：Lead）

- 用户反馈：建筑不好看。授权 Lead 把关美术方向，实在不行 Lead 自己设计。
- 现状：零依赖程序化 Canvas 绘制（无贴图资产），仅有的生成资产是 `scripts/gen-icon.mjs` 出的 exe 图标。
- 方向候选（待实施时定）：① 强化程序化绘制（统一色板/倒角/光照/轮廓语言）；② 生成器脚本离线烘焙等距精灵图集入库（沿用 gen-icon.mjs 路线，保持零运行时依赖）。验收方式：交付前后对比截图给用户过目。
