# 科幻版「等距指挥终端」风格提示词

> **历史参考（旧版）**：本文保留早期军工终端探索，不再作为现行美术规范。当前以
> [现代航天工程图谱](superpowers/specs/2026-10-24-aerospace-visual-redesign-design.md) 与 [design.md](design.md) 为准。

> 主题：**星球建造 + 太空计划 + 星际物流对战**（硬科幻工业感，不是霓虹赛博朋克）
> 风格内核沿用：等距 2.5D 预渲染 sprite + 军工指挥终端 HUD + 全程序化绘制（Canvas/CSS/SVG，零位图）
> 用法：整段粘给代码模型；或只取「四、风格前缀」贴到任意科幻任务前面。

## 一、游戏概念（写进提示词的部分）

《星区指挥终端 / ORBITAL COMMAND》单文件可玩 demo：
- **星球建造**：在等距星球地表铺基地（指挥中心、太阳能阵列、精炼厂、燃料站、发射台、机库、炮塔、货运坪）
- **太空计划**：发射台倒计时 → 火箭升空 → 星区图出现轨道站与航线
- **星际物流对战**：3 条星际航线（A-7 / B-2 / C-9）输送资源，敌方舰队周期性跃迁来袭，炮塔拦截
- 资源闭环：合金（建造）、能源（维持）、燃料（发射）、科研（解锁）；无限/快速建造放在 F3 调试台

## 二、风格基因（10 条，不可改）

1. **视角**：2:1 菱形等距，固定机位，无透视畸变；所有体积物由等距盒体拼成。
2. **渲染质感**：2.5D 预渲染 sprite——硬边、无描边、无 bloom、无景深、无 PBR。
3. **光照**：全图统一左上光；三面明暗 = 顶面 ×1.0 / 右面 ×0.86 / 左面 ×0.68；顶棱与左棱 1px rgba(255,255,255,.55) 亮边，下棱与右棱 1px rgba(0,0,0,.45) 暗边；接触阴影短而柔、统一偏右下。
4. **表面**：硬边拼花（瓦片/金属地砖），每块 = 底色 + 两层低频噪声斑块（12px / 5px，透明 8~14%）+ 1~2% dither + 1px rgba(0,0,0,.10) 暗缝；材质间硬边相接，禁止大面积渐变。
5. **色彩规则**：压深黑位（#050C0C / #0B1416 / #1D272B），低饱和；全图只允许 1 主强调 + 1 功能色 + 1 状态色：
   - 主强调 **琥珀金 #F0C050**：数值、激活态、关键按钮、发射倒计时；
   - 功能 **青 #88D8E8**：进度条、数据流、灯带、航线；
   - 状态 **雷达绿 #90C0A0**：正常状态、雷达、扫描点；
   - 例外：战斗/危险用 **警戒红 #C24A3A**，仅限警报与敌方单位。
   金色不做大面积背景，青色不用于正文文字，三色不同时出现在同一控件。
6. **HUD 材质**：哑光近黑钢板 + 1px 冷钢描边 #4E5C60 + 顶部 1px 内高光 rgba(255,255,255,.06)；直角或 ≤2px 圆角；短阴影 0 2px 6px rgba(0,0,0,.5)。禁止玻璃拟态、模糊、大阴影、霓虹外发光。
7. **字体**：中文 Noto Sans SC 700，字号只用 10/11/12/13/14px；英文副标题 10px 大写、letter-spacing .30em、色 #9AA4A6；数字/倒计时用等宽字体（tabular-nums）；行高 1.4；组件间距 6px。
8. **信息密度**：面板固定三段式 = 标题行（中文 + 右侧宽字距英文小字）/ 数据或列表 / 细进度条或状态点；1px 分隔线 #2C383E；图标只用 16px 内联 SVG 线性图标（stroke 1.5，currentColor）。
9. **动效克制**：进度条平滑、数字滚动、扫描线、航线光点流动；禁止弹跳、粒子爆炸、发光脉冲（战斗火花除外，且≤6px）。
10. **实现约束**：全部程序化生成（Canvas/CSS/SVG）；固定随机种子（mulberry32）；60fps；Network 面板零图片请求；无 emoji。

**硬科幻基调**：白陶瓷装甲 + 深灰结构 + 琥珀示数 + 青色数据灯，参考 NASA / 航天工业 / 重型机械；**不要**霓虹赛博、全息蓝紫、CRT 扫描线满屏。

【玩法闭环】
- 资源：合金/能源/燃料/科研，每秒产出，顶栏实时更新；调试台覆盖为无限。
- 建造：页签→选卡→地表放置（半透明 footprint + 网格吸附 + 绿/红合法性）；消耗合金；3s 建造进度（快速建造 ×1/12）。
- 发射：点击发射台 → "发射"→ 顶栏发射窗口倒计时 → 火箭升空（2 秒内沿等距斜轴飞出画面）→ 星区图出现货运光点沿航线移动 → 到达后合金 +燃料。
- 物流：物流页签显示 3 条航线（A-7 / B-2 / C-9）：名称 + 吞吐/分 + 状态点（绿/琥珀/红）+ 启用开关。
- 战斗：每 90~120s 敌方舰队跃迁（星区图红色三角 → 母星）；防御炮塔自动开火（1px 弹道线 + 4px 火花点）；警报条出现并倒计时；被击毁建筑冒 3 个灰色上飘圆点并留下焦痕。
